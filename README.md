agent-roast is a tiny program that writes one roast line about its own AI coding agent to a file: a single playful sentence about the agent's debugging habit — littering the code with `print('here')` markers and then not knowing which one fired.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
